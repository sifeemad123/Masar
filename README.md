# Masar | مسار

**Masar** is a simple, offline-first personal organizer built with Flutter to help you manage your day, build habits, and keep your study materials in one place.

## Features

- **Daily Tasks** — organize tasks by date and time, with local reminders.
- **Habits & Streaks** — track daily habits and keep an eye on your consistency.
- **Study Materials** — organize subjects, lessons, and completion progress.
- **Lesson Notes** — create and share notes for your lessons.
- **Offline-first** — your information is stored locally on your device; no account is required.

## Built With

- Flutter & Dart
- Provider for state management
- Hive for local storage
- Shared Preferences
- Flutter Local Notifications

## Run Locally

1. Install [Flutter](https://docs.flutter.dev/get-started/install).
2. Clone this repository:
   ```bash
   git clone https://github.com/sifeemad123/Masar.git
   cd Masar
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```
